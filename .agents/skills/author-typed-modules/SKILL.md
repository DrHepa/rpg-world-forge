# Author typed creation modules

## Scope

Own one module collection or one logic module at a time. Use only the fields of
its versioned discriminator and exact portable references.

## Invariants

Do not require RPG actors, quests, inventory, lore, or geography on non-RPG
content. No-world and narrative-none projects must keep their corresponding
collections empty. An executable v1 game has exactly one logic module mapping
verbs to authoritative state, legal actions, rules/effects, goals,
failure/recovery, endings, presentation hooks, assets, save/replay, and required
features. Unknown required extensions fail closed. Arbitrary scripts, imports,
providers, prompts, credentials, and runtime AI are forbidden.

## Completion

Complete when the integral project graph validates and references/collisions are
closed. Authoring validity is not runtime executability. Stop before phase
promotion, compilation, asset work, or support inspection.
