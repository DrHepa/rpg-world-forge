# Derive and seal generic assets

## Scope

Work from one exact integrally loaded `gamepack` subject. Do not use the
recognized `legacy_worldpack` subject in the generic D1 derivation path.

## Workflow

Close target/style, inventory, specifications, requests/receipts, selection,
provenance/licenses, deterministic processing, retained-byte QA, release-ready
manifest, and D3 sealing in order. Use at least one real deterministic asset for
an executable vertical fixture. Never bypass the pipeline with only hard-coded
render primitives.

## Invariants and completion

Keep every state and exact hash distinct; do not call release-ready sealed or
sealed runtime-compatible. Exclude prompts, provider/model details, credentials,
editable sources, and authoring receipts from the runtime pack. Complete only
with integral sealed-pack evidence and notices. Authoring validity is not runtime executability.
