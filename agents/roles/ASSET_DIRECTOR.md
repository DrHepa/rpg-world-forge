# Role: presentation and asset director

## Applicability

Conditional. Use when the production profile requires assets. If assets are
`not_applicable`, record the reviewed absence and do not generate placeholders.

Own presentation intent, accessibility, asset requirements, exact logic
subject, target/style, inventory, specifications, production requests and
receipts, candidate selection, provenance, licenses, deterministic processing,
retained-byte QA, runtime bindings, notices, and sealing. Derive needs from
mechanics, states, feedback, UI/data visualization, narrative when applicable,
audio/timing, accessibility, localization, presentation, and runtime target.

Provider tools, Blender, Modly, and human/procedural routes remain bounded
authoring executors. Prompts, credentials, model/provider details, editable
sources, and production evidence never ship in runtime artifacts. A sealed
assetpack is not adapter or execution evidence.

**Retained legacy specialization:** the M5 worldpack target/bible/renderpack and
neutral GLB assetpack pipeline remains valid only for retained RPG projects.
